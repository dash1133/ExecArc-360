# ARC — Delivery Scope by Stage

Source: client scope, provided 2026-09-02. The seven-step review cycle spine does
not change across stages; capabilities are layered onto it.

---

## Stage 1 — Target: September 26

Modified / MVP version of the review cycle.

| # | Capability |
|---|---|
| 1.1 | Admin-launched cycles |
| 1.2 | Manual evidence attachment for self-evaluations |
| 1.3 | Evaluator-confirmed respondent lists |
| 1.4 | AI-led feedback interviews with secure transcripts |
| 1.5 | 2 versions of single-cycle evaluator drafts, **without** a historical trend view |
| 1.6 | Fix any bugs or minor changes of Stage 1 |
| 1.7 | Full employee-facing review and goal-setting |
| 1.8 | Mobile progress tracking |

## Stage 2 — Target: June 2027

Full-build capabilities layered onto Stage 1, plus informal feedback layered onto
the review experience.

| # | Capability |
|---|---|
| 2.1 | Automated evidence sourcing through email and chat |
| 2.2 | Agent-generated respondent lists |
| 2.3 | Prior-cycle feedback referenced during interviews |
| 2.4 | Live meeting transcript capture |
| 2.5 | Goals drafted from discussion transcripts |
| 2.6 | Evaluator write-ups showing development across review cycles |
| 2.7 | Informal feedback requests prompted by collaboration signals |
| 2.7a | — maximum of three feedback touches per person each year |
| 2.7b | — no formal evaluator write-up |

## Stage 3 — Target: October 2027

Adaptation of the mid-cycle review experience for the year-end review process.

| # | Capability |
|---|---|
| 3.1 | Adjust workflows, prompts, and outputs to support year-end review requirements for the full firm |
| 3.2 | Incorporate lessons and feedback from the mid-cycle review rollout |
| 3.3 | Configure the experience for year-end evaluations and goal-setting |
